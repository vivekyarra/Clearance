# Clearance: Know if a robot fits before you buy it

Scan a real room with an ordinary iPhone. Clearance builds a measured digital twin, checks which commercial delivery
robots and AMRs can work there, simulates them against real foot traffic, and decides the verdict in code.

Built for the Nebius x NVIDIA Global AI Hackathon, Physical AI track.

```bash
pip install -r requirements.txt
PYTHONPATH=. pytest -q tests
```
